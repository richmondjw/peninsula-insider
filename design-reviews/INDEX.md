# Peninsula Insider — Weekly Design Reviews

This directory holds the weekly design-review memos produced by the
`pi-weekly-design-review` cron job (Sundays 22:00 UTC). Each memo
identifies one actionable design improvement for the PI Astro front-end,
with the exact change ready to implement.

**Playbook:** [../docs/design-review-playbook.md](../docs/design-review-playbook.md)
**Cadence:** weekly, Sunday 22:00 UTC (Monday morning Melbourne)
**Filename format:** `YYYY-WWW.md` (ISO week, e.g. `2026-W18.md`)
**Owner:** Pixel (Marketing team) via Remy
