## Recommendation of the week

**Title:** Tokenise the shadow base colour — normalise 3 competing warm-brown rgba values to one `--shadow-ink` variable in `:root`

**Why it matters:** `global.css` contains 18 box-shadow declarations using 4 distinct rgba base colours. Three of those are all trying to be the same brand warm-brown — `rgba(34, 24, 16, ...)`, `rgba(30, 27, 24, ...)`, and `rgba(40, 28, 14, ...)` — producing a barely perceptible but cumulative incoherence in the elevation system. The 8 instances of `rgba(34, 24, 16, ...)` are correct (closest to brand dark). The 10 instances across the other two values are drift. Normalising all warm-brown shadows to a single variable eliminates the drift and makes the elevation system maintainable: any future card shadow just uses `rgba(var(--shadow-ink), 0.07)` and is guaranteed in-brand without hunting the stylesheet.

**Files to change:**
- `next/src/styles/global.css` (`:root` block + 10 shadow declarations)

**Proposed change:**

Step 1 — add the token to `:root`:
```css
/* Shadow ink — the warm-brown base for all card/layer elevation shadows */
--shadow-ink: 34, 24, 16;
```

Step 2 — replace the 10 drifted declarations (leave `rgba(0,0,0,...)` pure-black shadows on tour cards and dark surfaces alone — those are intentional):

```diff
/* Lines ~3197, 3827, 3937, 5752, 5921 — rgba(30, 27, 24, ...) */
- box-shadow: 0 14px 32px rgba(30, 27, 24, 0.07);
+ box-shadow: 0 14px 32px rgba(var(--shadow-ink), 0.07);

- box-shadow: 0 10px 24px rgba(30, 27, 24, 0.06);
+ box-shadow: 0 10px 24px rgba(var(--shadow-ink), 0.06);

/* Lines ~480, 9462, 9968 — rgba(40, 28, 14, ...) hover shadows */
- box-shadow: 0 18px 40px -20px rgba(40, 28, 14, 0.35);
+ box-shadow: 0 18px 40px -20px rgba(var(--shadow-ink), 0.35);

- box-shadow: 0 22px 50px -22px rgba(40, 28, 14, 0.4);
+ box-shadow: 0 22px 50px -22px rgba(var(--shadow-ink), 0.4);

- box-shadow: 0 12px 24px -12px rgba(40, 28, 14, 0.4);
+ box-shadow: 0 12px 24px -12px rgba(var(--shadow-ink), 0.4);

/* Lines ~9129, 9264 — rgba(40, 28, 14, ...) focus/ring shadows */
- box-shadow: 0 0 0 1px rgba(40, 28, 14, 0.25);
+ box-shadow: 0 0 0 1px rgba(var(--shadow-ink), 0.25);
```

Then backfill the 8 existing correct declarations to also use the token (optional but recommended in the same pass):
```diff
- box-shadow: 0 18px 40px rgba(34, 24, 16, 0.06);
+ box-shadow: 0 18px 40px rgba(var(--shadow-ink), 0.06);
```

**Estimated effort:** S (15-20 minutes — search-and-replace in `global.css`, confirm in dev with eyes)

**Risk:** Barely perceptible shade shift on 10 shadows. `rgba(30, 27, 24, ...)` becomes very slightly warmer; `rgba(40, 28, 14, ...)` becomes very slightly cooler. No layout change, no z-index change, no component restructure.
