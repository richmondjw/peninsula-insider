## Recommendation of the week

**Title:** Make `ExperienceCard` fully clickable with the stretched-link pattern and remove its redundant CTA.

**Why it matters:** `ExperienceCard` currently presents three separate click targets to the same destination (the hero image link, the title link, and the "Open the guide" CTA). This is a minor accessibility nuisance for screen-reader users and a visual inconsistency: `VenueCard` already solved this with `.venue-card--editorial`, which stretches the title link over the whole card and hides the CTA. Unifying the two cards reduces maintenance surface and gives readers the cleaner interaction they already get from venue grids.

**Files to change:**
- `next/src/styles/global.css:3147-3180` — add stretched-link pseudo-element, hide CTA
- `next/src/components/ExperienceCard.astro:47-70` — remove the standalone CTA link

**Proposed change:**

In `global.css`, after the existing `.experience-card__title a:hover` rule (line 3156), add:

```css
.experience-card { cursor: pointer; }
.experience-card__title a::before {
  content: '';
  position: absolute;
  inset: 0;
  z-index: 2;
}
.experience-card__cta { display: none; }
.experience-card:hover .experience-card__title a { color: var(--accent); }
```

In `ExperienceCard.astro`, remove the CTA anchor (lines 68-70 approx):

```diff
-    <a href={`/explore/${slug}`} class="experience-card__cta">Open the guide →</a>
```

The hero image link already carries `aria-hidden="true" tabindex="-1"`, so it is invisible to assistive technology. The title link becomes the sole accessible target and, via the pseudo-element, the entire card is clickable. The `z-index: 2` sits above the image link but below the `PiSaveActions` pill (which uses its own higher z-index), so saving still works.

**Estimated effort:** S (under 20 minutes — two files, ~12 lines changed, no call-site updates needed)
**Risk:** Low. The card is used in 13 locations but always in editorial grids where the stretched-link behaviour is expected. Spot-check one grid at 375px to confirm the save-pill still receives clicks.
