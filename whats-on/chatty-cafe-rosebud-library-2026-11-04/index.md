Editor's verdict

A local, low-commitment way to make time for conversation.

Rosebud Library lists a Chatty Café session on Wednesday 4 November, from 10am to noon. It is a chance to share a cuppa and conversation in a local library setting. The organiser welcomes everyone and says no bookings are required.

The programme is part of the Chatty Cafe Scheme, which encourages social connection through conversation. You do not need to arrive with a group. Treat this as a relaxed community session rather than a scheduled performance or a formal class.

The listed venue is Rosebud Library on McDowell Street. Check the library’s source page before travelling for any changes to this particular session. If you have access requirements, contact the library directly so you can plan your visit. This listing confirms only the dated session shown here; it does not promise that every future Wednesday will run.
