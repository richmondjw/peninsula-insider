## Gotchas

- **CRLF line endings.** Most PI source files have CRLF. The first version of `governance-audit.mjs` had a regex bug because the YAML frontmatter parser didn't normalise line endings — fixed in tranche 1, but worth knowing if you write similar tooling. Always `.replace(/\r\n/g, '\n')` before splitting on `\n` for content-collection markdown.
- **Worktree vs main checkout share `.git`.** The main checkout's working directory has unrelated uncommitted changes. Be aware that `cd ../../..` puts you in a different working tree on the same repo.
- **`git status` warnings.** Git emits LF-vs-CRLF warnings on every commit because the worktree is on Windows but content uses LF. Cosmetic only — content lands as-checked-in.
- **The `tmp-*` license values are valid.** They're in the schema enum on purpose — they're meant to be tracked, not block. The audit treats them as WARN, not ERROR. Don't delete them mechanically; replace with proper licenses on a rolling basis.
- **`ops/operating-surface.md` is a manual artifact.** It must be updated whenever a new cron or workflow lands. There's no automation enforcing that yet — see Stage B item 5.
