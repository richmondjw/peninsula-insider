# Peninsula Insider — Content Governance & Rollout Plan

## Aim
Implement the new structure quickly without creating a second layer of mess.

The operational goal is simple: every existing and future page should sit inside a clear role, review cadence, and ownership model.

## Migration methodology

### Step 1: inventory
Create a master inventory of current high-value URLs and classify each page by:
- current section
- current intent
- target section
- content type
- freshness sensitivity
- overlap risk
- recommended action

### Step 2: assign action type
Use one of five actions:
- keep
- rewrite
- move
- merge
- retire / redirect

### Step 3: cluster duplicates
Audit highest-risk overlap clusters first, including:
- restaurants / long lunches / winery lunches
- weekend itineraries
- seasonal Peninsula guides
- best-of roundups
- event / opening / festival content

### Step 4: migrate by cluster, not randomly
Do not clean pages one by one in isolation. Migrate by topic cluster so cannibalisation is resolved properly.

## Governance cadence by lane

### Eat / Stay / Wine / Explore
**Cadence:** quarterly review

Check for:
- venue still open
- major descriptor accuracy
- outdated copy blocks
- broken links
- taxonomy fit

### Plans
**Cadence:** seasonal review, plus trigger-based updates

Check for:
- sequencing still makes sense
- venues still fit the plan
- weather / season relevance
- linked pages still valid
- recommendation still feels decisive and current

### What's On
**Cadence:** weekly review, with live update triggers

Check for:
- dates
- time sensitivity
- event still active
- opening still relevant
- editorial value threshold
- duplication against other What’s On pages

### Journal
**Cadence:** ongoing editorial review, light periodic maintenance

Check for:
- voice quality
- factual confidence
- link health
- whether a piece has become structurally better suited to another lane

## QA checklist by content lane

### Evergreen reference QA
- correct section
- clear primary keyword / intent
- factual accuracy
- internal links to related Plans / What’s On where useful
- no stale date-led framing in core copy

### Plans QA
- clear audience / scenario
- clear duration and context
- confident sequencing
- no excessive option sprawl
- linked reference pages exist and are current
- not duplicating a What’s On or Journal job

### What’s On QA
- current and date-valid
- truly worth including
- concise why-it-matters framing
- no filler listings
- correct urgency / expiry handling
- archive or refresh path defined

### Journal QA
- real editorial angle
- local specificity
- no generic listicle drift
- not secretly an itinerary or event roundup
- voice strong enough to justify publication

### Copy / editorial agents
- draft within assigned lane
- must declare page intent before drafting
- cannot publish mixed-intent pages by default

### Governance agents / QA layer
- validate taxonomy fit
- flag overlap and cannibalisation risk
- enforce review cadences
- surface stale pages

## Two-week execution backlog

### Week 1 — structure lock + audit start
1. Confirm canonical section roles and page-intent rules
2. Create migration inventory sheet / document
3. Pull top 100–150 priority URLs
4. Tag each URL with target lane and recommended action
5. Identify top 10 overlap clusters
6. Finalise nav and landing-page requirements for Plans / What’s On

### Week 2 — first migration wave
7. Resolve first three high-impact overlap clusters
8. Draft redirect / merge list
9. Define homepage block rebuild against new structure
10. Set review cadences and assign owners
11. Establish What’s On weekly operating workflow
12. Establish Plans seasonal review workflow

## Dependencies
- canonical taxonomy must be locked before broad migration
- homepage redesign should follow section-role agreement
- redirects should be mapped before major moves
- What’s On workflow needs a clear weekly editor / owner

## Risks
1. Moving too fast and just relabelling existing overlap
2. Publishing new mixed-intent pages during the transition
3. Leaving redirects until late
4. Letting What’s On become an exhaustive calendar
5. Under-resourcing review of high-change pages

## Control rules during rollout
- freeze unnecessary new evergreen page creation until lane rules are active
- all new briefs must state lane + page intent
- if a page cannot be classified clearly, do not publish it yet
- prioritise consolidation over expansion

- fewer duplicated concepts
- clearer review ownership
- a visible pathway from structure to live implementation
