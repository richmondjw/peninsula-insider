# Field Notes — standing production process

Source of truth for the weekly "Field Notes" email (Peninsula Insider's subscriber newsletter), effective issue No. VII onward. Supersedes any brief-per-issue workflow. Captured verbatim from James's brief dated 2026-08-01; see `field-notes-no-vi-revision-brief-2026-08-01.md` for the issue-specific revisions that preceded this standing process.

## 1. The fixed module order

Every issue is these modules, in this order. A module with nothing worth saying is omitted, never padded. A shorter honest issue beats a full template.

| # | Module | Rules |
|---|---|---|
| 1 | Masthead | "Field Notes" + "Written from inside the region" + roman-numeral issue no. + date range. Never changes. |
| 2 | Intro | Two lines maximum. Past tense, sets the week's mood. Editorial writes it; design never pads it. |
| 3 | The lead: today's move | The one actionable pick for send day. Exactly one CTA and it is a verb ("Book…", "Go before…"), never "Read more." |
| 4 | Weather strip | One line: day, temperature, sky, sunset time. Small caps between hairlines. |
| 5 | Two secondary picks | Day-stamped, category-tagged. Images only if rights-cleared (see §3); otherwise text cards. |
| 6 | From the replies | One reader reply, first name only. If no usable reply arrived this week, omit the module. Never fake it, never self-quote. |
| 7 | Also this week | Up to three compact text rows, chronological. No thumbnails. |
| 8 | One booking note | One time-sensitive sentence + one link. Navy card. If nothing genuinely closes or opens this week, omit. |
| 9 | Poll | One tap, beehiiv native. Same question format weekly so answers are comparable. |
| 10 | Reply prompt + sign-off | Verbatim, every issue: "Been somewhere brilliant this week that we should know about? Just hit reply. We read everything." Then "The Insider." |
| 11 | Footer | Issue no., dates, nav links (this weekend · what's on · journal), unsubscribe, street address. |

## 2. Copy rules (design enforces these too; the last eyes before send are yours)

- No em-dashes, anywhere. Replace with comma, semicolon, colon, or parentheses. Hard house rule across every PI surface.
- No prices. Ever. "Ticketed" or "booking required" instead.
- Every factual claim traces to a source editorial has supplied (the venue record or the week's fact sheet). If a line names a venue, a date, a number, or a superlative and there's no source next to it, send it back; don't design around it. The Avani/Elgee error in No. VI is exactly what this rule exists to catch.
- Venue names exactly as the site spells them. Note the traps: "Hotel Sorrento" (the 1870s hotel) and "The Sorrento Hotel" (the pub) are different venues. When in doubt, check the venue page URL editorial provides.
- One CTA per module, and the lead's CTA is always a verb.
- Verdict lines are sacred. Copy that arrives in quotation marks from editorial ships unedited; typographical changes only.

## 3. Image rules

- Only rights-cleared images, cleared specifically for email use. Editorial supplies the cleared list with each issue; nothing outside that list goes in.
- No near-enough stock. If no cleared image exists for a pick, use the typographic card: navy panel, verdict line large in the display face. This is a first-class treatment, not a fallback of shame.
- The hero must depict the lead. A wrong image under "written from inside the region" costs more than no image.
- Alt text on every image, written as a description of what's pictured, never a filename.
- Recognisable people require a release on file; when unsure, crop or choose again.

## 4. Weekly rhythm

| When | What | Who |
|---|---|---|
| Mon | Week's picks + fact sheet + cleared-image list delivered | Editorial |
| Tue | First layout in beehiiv; queries on any unsourced claim sent back | Design |
| Wed | Copy corrections + "From the replies" selection + booking note | Editorial |
| Thu AM | Final layout + 3 subject/preview pairs + self-QA (§5) complete | Design |
| Thu PM | James approves subject choice and sends/schedules | James |

The send is the Thursday morning slot the following week, aligned with the site's weekly campaign publish. The email never goes out before the site content it links to is live.

## 5. Pre-send QA checklist (designer runs, every issue, no exceptions)

- [ ] Zero em-dashes (search the export for the em-dash character)
- [ ] Zero prices (search for "$")
- [ ] Every link carries `utm_source=email&utm_medium=newsletter&utm_campaign=field-notes-<nn>`
- [ ] Every link clicked once in the built email; no 404s, links land on live pages
- [ ] Lead CTA is a verb and points at a booking/action URL
- [ ] Every image is on this week's cleared list and has alt text
- [ ] Venue names match the site's spelling exactly
- [ ] Categories (EAT / WINE / STAY / EXPLORE / CULTURE) match the pick's actual type
- [ ] Dates: range spacing correct, day-stamps match the pick dates, no missing Saturday without editorial sign-off
- [ ] Dark-mode preview checked (navy blocks legible, cream doesn't invert)
- [ ] Mobile 375px: cards stack, compact rows don't wrap badly
- [ ] Subject ≠ preview text; three pairs delivered, concrete over clever
- [ ] Test send to editorial + James before scheduling

## 6. Roles in one line each

- **Editorial** owns facts, verdicts, pick selection, the reply selection, and the booking note. Everything factual arrives with a source.
- **Design** owns layout, imagery within the cleared list, typography, dark mode, mobile, UTMs, and the QA checklist. Design is the final gate: if a claim has no source or an image has no clearance, it comes back, it doesn't ship.
- **James** owns the subject-line choice and the send.

## 7. What never changes without a decision from James

The masthead name, the module order, the palette, the sign-off, the reply prompt, and these process rules. Everything else is design's to improve; propose changes in the Thursday note rather than shipping them silently.
