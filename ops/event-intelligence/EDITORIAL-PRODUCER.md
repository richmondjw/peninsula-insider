Default disabled. `runEditorialProducer` accepts an explicit trusted host configuration and prepares immutable private receipts only. It does not install records, change review packets, resolve production alerts, write a public manifest, schedule itself or publish.

Trusted configuration schema1: registryHash (exact reviewed registry), cadenceHours12, items (1–5 unique candidateId, primaryUrl, registrationUrl, boundaryUrl). URLs must match admitted hosts; primary URL must match the original candidate; linked registration must subsequently be proven by the captured organiser page; boundary URL matches the registered boundary exactly. Default transport is existing fetchEvidence with public DNS checks, manual redirects, timeout and2MB response limit. Dependency injection is for clearly synthetic tests, not a proof of real transport.

Input packet snapshot is bounded64MiB/5000 candidates. The original packet bytes are checked again before receipt admission. Human holds and edits are preserved by the accepted verifier; source changes hold instead of replacing facts. Actual public inventory is independently checked for conflicts and reread before receipt emission. Every output directory is a unique run UUID, captures and final receipt use exclusive writes. Each UUID begins with immutable pending.json (incomplete state, config/input fingerprints). CAS/inventory or preparation failure writes terminal receipt.json state failed with capture bindings and zero admitted proposals; absence of a terminal complete receipt is never success. These files remain retained for investigation. No review or publication state is rewritten.

Output proposals: review-content-patch (review-only record and content-bound manifest entry) or withdraw-or-retain-hold. Failed/expired/mismatched source, cancellation, explicit hold or canonical conflict yields an actionable private alert. A later fresh successful run is a new receipt, not a rewrite of the failure. Proposed12-hour cadence is not configured operation; the caller must not treat failure as success or install stale proposals.
