Default disabled. This module prepares immutable private files only; there is no apply, commit, push or deployment function. Existing release workflow remains the eventual publisher.

Required trusted caller inputs: expected private service/output roots, current committed service run and exact service/producer receipt SHA256 pins, reviewed registry pin, canonical review packet and expected content root. Service head binds its receipt and ledger. Producer receipt must match the committed service proposals/alerts and current packet/registry/inventory; a numeric score or actor flag is insufficient. Source body/full capture metadata pins are verified and accepted factual policy is re-executed at release clock. All capture, packet, registry, head and inventory bindings are rechecked before final plan admission. Missing/expired/conflicting facts refuse publication preparation. Optional price/media remain omitted.

Each proposed file has expected-existing SHA256 or absent expectation and after hash. Full original bytes are retained privately for exact rollback. Published status exists only in private proposed JSON; canonical source records remain unchanged. Duplicate identity/target, unrelated occupied slug, legacy James/manual records and explicit human holds/cancelled/postponed/rejected states are protected. Withdrawal prepares review status only for the same prior automated actor/event ID following a pinned committed held proposal; it never claims organiser cancellation. Fresh active-source publication always reexecutes evidence, while conservative withdrawal does not grant factual publication eligibility.

Orphan directories from failed preparation are not admitted; patch-plan.json is written last. No removal of existing private history occurs. Future guarded apply must recheck all file expectations and current evidence, apply only in an isolated review checkout, execute accepted build and independent gates, and publish through authorised release workflow. Failed release retains live version and rollback bytes; receipt creation alone is not release acceptance.
