# Mailing-list request — draft emails

Ready-to-send drafts for adding **remy@peninsulainsider.com.au** and
**emma@peninsulainsider.com.au** to a venue's mailing list. Use these when a
venue has no public signup box (or instead of hunting for one). Replace
`{{VENUE}}` with the venue name; everything else is ready to go.

Send from the relevant address. The simplest play is to send **one** of these
from each inbox to the venue's contact address (or paste it into their website
contact form). That way both addresses end up on the list.

---

**To:** _venue contact address_
**From:** remy@peninsulainsider.com.au
**Subject:** Please add us to your mailing list — Peninsula Insider

> Hi {{VENUE}} team,
>
> I'm Remy from Peninsula Insider — we cover what's on across the Mornington
> Peninsula. Could you please add me to your mailing list so we don't miss
> your events, menu changes, and seasonal news?
>
> **Email to add:** remy@peninsulainsider.com.au
>

> Thanks so much, and keep up the great work.

> Remy

### Notes
- Many venues use a **website signup box** (footer or a "Newsletter"/"Join"
  page) — that's faster than emailing. Use the register to track which method
  you used per venue.
- A signup box usually takes **one address at a time**, so submit it twice
  (once for remy@, once for emma@).
- Expect a **double opt-in confirmation** email in each inbox for many venues
  (Mailchimp/Klaviyo) — you must click the confirm link or the subscription
  won't activate.
