The Peninsula in heavy autumn rain is a different version of itself — not diminished, just reorganised. The cellar doors that run indoor table service rather than outdoor terraces come into focus. The restaurants that anchor a long Thursday lunch are exactly right for a day when there is no reason to rush back outside. The Hot Springs, which operates in any weather because the pool temperature is controlled and the water is warm, fills faster on wet days.

Two full rain days — Thursday and Friday — is not a short-notice problem if you treat it as a prompt to plan the visit properly. The Springs has a Bathe in Cinema event on Friday evening (David Attenborough's Ocean, poolside at 6:30pm) and a Kodomo no Hi celebration on Saturday. Cellar doors that run indoor tastings by appointment on weekdays include the smaller Main Ridge producers. Montalto's restaurant is open for lunch, rain or shine, with the kind of set menu that works best when there is no outdoor agenda competing for your time.

None of this requires the weather to cooperate. It requires knowing which rooms are worth the drive.
